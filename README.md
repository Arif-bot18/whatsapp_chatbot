# 🎓 AI WhatsApp Sales Assistant for Coaching Institutes

An AI-powered WhatsApp chatbot built with **FastAPI**, **Gork**, **Meta WhatsApp Cloud API**, and **Supabase** to automate student inquiries, qualify leads, and increase admissions for coaching institutes.

---

## 🚀 Features

- 🤖 AI-powered conversations using Gork
- 📱 WhatsApp integration using Meta Cloud API
- 📝 Collects student information automatically
- 🎯 Lead qualification (High, Medium, Low)
- 💬 Answers student questions naturally
- 📅 Demo/Class booking
- 🔄 Automatic follow-up system
- 👨‍💼 Human takeover mode
- 📊 Lead management with Supabase
- 📜 Conversation history logging
- ⚡ Real-time webhook handling with FastAPI

---

## 🛠️ Tech Stack

- Python
- FastAPI
- Gork API
- Meta WhatsApp Cloud API
- Supabase
- Uvicorn
- HTML (Landing Page)
